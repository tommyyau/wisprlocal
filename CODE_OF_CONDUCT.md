# Code of conduct

WisprLocal adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct, for issues, pull requests, discussions and any other project space.

In short: be welcoming, be patient and assume good faith; criticise ideas, not people; no harassment, insults, sexualised language or imagery, or publishing anyone's private information. Maintainers may edit or remove contributions, and may temporarily or permanently ban anyone, in line with the Covenant's enforcement guidelines.

**Reporting.** To report unacceptable behaviour, use [GitHub's private reporting form](https://github.com/tommyyau/wisprlocal/security/advisories/new) (repository → Security → Report a vulnerability), and mark it as a conduct report. Do not use public issues for sensitive reports. Reports are handled confidentially.
